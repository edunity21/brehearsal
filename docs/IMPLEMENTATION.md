# 구현 현황

이 문서는 PRD의 목표와 현재 소스의 동작을 구분합니다. PRD의 성능 목표가 모두 실측으로 충족되었다는 의미는 아닙니다.

## 구현됨

- HTML/CSS/JavaScript 반응형 앱. 별도 빌드나 프런트엔드 의존성 없음.
- MediaRecorder 카메라·마이크 녹화, 전면 카메라 요청, 거울 미리보기.
- 기본 목표 600초, 최대 누적 녹화 900초, 일시정지 제외.
- 250ms 간격으로 활성 시간을 확인하여 900초 도달 시 종료 요청. 실제 파일 끝은 브라우저의 인코딩·이벤트 처리 지연에 따라 미세하게 달라질 수 있음.
- Web Speech API 또는 인증된 Node.js 서버 WAV 전사.
- 문자 기반 순차 정렬, 조사·어미 차이 후보, 반복 발화 대응, 수동 위치 복구.
- 원문 변형 없는 자막 표시. 사용자가 입력한 발음 대응만 비교 표현에 적용.
- 동일 시간 축의 목표·예상 막대, 현재 위치 커서와 권장 시간 표식.
- 녹화 조각과 메타데이터를 IndexedDB에 저장. 저장 실패 시 현재 탭 메모리에서 영상 내보내기.
- 저장 목록, 재생, 대조 기록 다운로드, 검토 결과 수동 분류, 세션 삭제.
- GitHub Pages 정적 배포 워크플로와 선택적 음성 인식 서버.

## 실제 동작의 제한

- 음성 인식 결과가 틀릴 수 있으므로 자동 대조는 확정 채점이 아니다. 검토 후보로 표시한다.
- 짧은 발화, 큰 순서 변경, 먼 문장으로 건너뛰기는 자동 추적에 실패할 수 있다. 원문 위치 선택으로 복구한다.
- 순서 변경을 독립 유형으로 정교하게 분류하지 않고 불일치·추적 불확실 후보로 처리한다.
- 아직 말하지 않은 부분은 흰색으로 남는다. 원문 도달률은 정확도 점수가 아니다.
- 숫자·약어의 말하기 형태가 다르면 발음 대응 설정이 필요하다.
- 서버 모드는 약 5초마다 분석하므로 PRD의 2초 이내 자막 반응 목표를 충족하지 않는다. 기본 모드의 지연도 브라우저 서비스에 의존한다.
- 재생 자막은 확정 인식 이벤트 시점에 맞춰 갱신된다. 음소/단어별 정밀 타임스탬프가 아니므로 PRD의 500ms 동기 목표는 아직 보장하지 않는다.
- 영상 파일에는 자막·타이머가 합성되지 않는다. 앱 재생 화면에서 표시한다.
- 사진 앱 직접 저장, 홈 화면 설치, 오프라인 음성 인식, 기기 간 동기화는 구현하지 않았다.
- 백그라운드 전환 시 앱이 감지할 수 있으면 일시정지한다. OS가 즉시 프로세스를 종료하면 마지막 조각 또는 메타데이터가 손실될 수 있다.
- 저장 공간, 인코더 상태, 브라우저 강제 종료에 대한 완전 복구는 보장하지 않는다.
- 미리보기만 거울 반전한다. 저장 영상은 카메라 원래 방향이며 재생 화면에서 확인할 수 있다.

## 검증 상태

- 원문 비교·발음 대응·반복·시간 계산·한도·WAV 생성·서버 인증 등 자동 검사 통과.
- 로컬 서버 HTTP 응답, JavaScript 구문 검사 통과.
- 데스크톱 내장 브라우저에서 초기 화면 및 제공 원고 불러오기 확인.
- 실제 카메라·마이크, 실제 유료 음성 API, iPhone/iPad/Android 기기별 15분 녹화는 이 제작 환경에서 검증하지 않았다.

모바일 UI는 구현되어 있으나 지원 기기 인증을 완료한 제품으로 표현하지 않는다. 사용 기기에서 TESTING.md의 점검을 진행한다.
