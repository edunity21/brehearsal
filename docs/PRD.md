# 원문 암기 발표 연습 앱 PRD

- 문서 버전: 1.3 — 앱 소스 통합 패키지
- 작성일: 2026-10-18
- 제품명: BRIDGE · 발표 연습실
- 대상: 휴대폰, 태블릿, PC
- 기본 발표 목표: 10분
- 최대 녹화: 세션당 누적 15분(900초), 일시정지 제외
- 문서 성격: 제품 요구사항. 실제 구현 및 검증 상태는 [IMPLEMENTATION.md](IMPLEMENTATION.md) 참조

## 1. 목적

발표자가 자신의 모습을 촬영하면서 확정된 원고를 토씨 하나 빠뜨리지 않고 재현하고, 제한 시간에 맞춰 발표하도록 돕는다. 카메라 화면 하단에 원문 자막을 표시하고 발화에 따라 색을 바꾼다. 경과 시간과 권장 진행 속도, 현재 속도에 따른 예상 완료 시간을 가로 막대로 비교한다.

원고의 요약·윤문·의미가 같은 표현으로 대체하는 것은 목표가 아니다. 연습은 확정 원문을 기준으로 한다.

## 2. 사용 상황

- 심사위원 앞에서 원고 없이 10분 발표를 준비하는 발표자.
- 휴대폰·태블릿을 거치하고 전면 카메라를 보며 연습.
- 초기 연습은 10분을 초과할 수 있으므로 최대 15분까지 녹화.
- 녹화 후 시선·자세·말투·원문 재현을 검토하고 다시 연습.

## 3. 제품 원칙

1. 원문은 자동으로 변경하지 않는다. 오탈자도 사용자가 확정하기 전에는 유지한다.
2. 음성 인식과 암기 평가는 구분한다. 인식이 불확실하면 실제 발화 오류로 확정하지 않는다.
3. 얼굴·원문·핵심 시간을 한눈에 볼 수 있게 한다.
4. 모바일 세로·가로 화면과 터치를 기본 설계 조건으로 삼는다.
5. 녹화는 기기 내 저장을 우선하고 외부 음성 전송은 명확히 안내한다.
6. 원문 진행률과 정확도를 혼동하지 않는다. 건너뛴 구간은 정확히 말한 것으로 처리하지 않는다.

## 4. MVP 범위

- 원고 입력·수정·확정, 제목, 목표 시간 설정.
- 카메라 미리보기와 음성을 포함한 영상 녹화.
- 하단 원문 자막, 발화 추적, 색상 변화, 수동 위치 복구.
- 경과·권장·예상 시간 및 가로 시간 막대.
- 일시정지, 재개, 종료, 15분 자동 종료와 저장.
- 녹화 목록, 재생, 검토 지점, 영상 파일 내보내기.
- 휴대폰·태블릿·PC 반응형 화면.

후속 범위: 자막 숨김 시험, 구간별 시간 수동 지정, 회차별 변화 비교, 자막·시간 합성 영상, 계정 동기화, 정밀 단어 타임스탬프.

MVP의 다운로드 영상은 카메라 영상과 음성을 포함한다. 자막·시간 그래픽 합성은 후속 기능이며, 원문 대조는 앱 재생 화면에서 확인한다.

## 5. 사용자 흐름

1. 원고를 입력하고 비발화 기호·미정 관리번호·기관명을 확인한다.
2. 목표 시간을 설정하고 발음 대응을 확인한다.
3. 카메라·마이크와 음성 인식 방식을 확인한다.
4. 오디오 외부 전송 안내를 확인하고 연습 시작을 누른다.
5. 3초 카운트다운 후 녹화·타이머·음성 추적을 함께 시작한다.
6. 하단 자막을 보며 발표한다. 시간 막대와 자막 상태가 갱신된다.
7. 사용자 종료 또는 15분 한도 도달 시 녹화를 마무리하고 저장한다.
8. 영상과 검토 지점을 확인하고 필요한 파일을 내보낸다.

## 6. 화면 요구사항

### 준비 화면

- 제목, 원고, 목표 시간, 음성 인식 방식, 발음 대응, 카메라 확인, 연습 시작.
- 목표는 기본 10분이며 1~15분 범위에서 설정한다. 최대 녹화 한도는 15분으로 고정한다.
- 녹화 중에는 원고와 설정을 변경할 수 없다.
- 원본 표시 문자열과 비교용 정규화 문자열을 분리한다.
- 문장 속 숫자나 약어의 발음 대응을 사용자가 설정할 수 있다.

### 발표 화면

```text
● 녹화 중                  경과 03:20 / 목표 10:00
┌────────────────────────────────────────────┐
│                 내 카메라 영상              │
│                                            │
│  원문 자막: 말한 부분에 따라 상태·색 변경     │
└────────────────────────────────────────────┘
권장 도달 03:00    예상 총 11:07    녹화 가능 11:40
목표  ██████████                  10:00
예상  ███████████▏                11:07
      ↑ 현재 · ┆ 권장 도달 · 녹화 한도 15:00
                  [일시정지] [종료·저장]
```

- 휴대폰 세로: 얼굴 중심의 카메라, 영상 하단 반투명 자막, 그 아래 시간과 조작 버튼.
- 휴대폰 가로: 영상 옆에 시간 패널을 배치해 낮은 화면 높이를 활용한다.
- 태블릿·PC: 원고 설정과 촬영 영역을 나란히 배치하고 집중 화면을 제공한다.
- 자막은 기본 2~3줄, 글자 크기 조절과 자동 스크롤을 제공한다.
- 기기 회전으로 세션·타이머·현재 위치를 초기화하지 않는다.
- 터치 조작, 안전 영역, 모바일 주소창 크기 변화에 대응한다.
- 색 외에도 밑줄과 상태 텍스트로 구분한다.
- 거울 미리보기 선택과 저장 영상 방향 안내를 제공한다.
- 화면 켜짐 유지 기능은 지원되는 환경에서 사용한다.

## 7. 자막과 발화 대조

| 상태 | 표시 | 의미 |
|---|---|---|
| 대기 | 흰색 | 아직 말하지 않음 |
| 현재 위치 | 노란색 강조 | 현재 추적 위치 또는 임시 인식 |
| 인식 일치 | 초록색·밑줄 | 확정 인식 문자열이 원문과 대응 |
| 차이 후보 | 주황색·점선 | 누락·대체·추가 등 검토 필요 |
| 인식 불확실 | 상태 문구 | 위치를 확신하지 못함, 수동 복구 가능 |

- 조사·어미 변경은 차이 후보로 처리한다. 뜻이 같다는 이유로 일치 처리하지 않는다.
- 띄어쓰기·문장부호 차이는 발화 오류에서 제외한다.
- 숫자·영문 약어는 사용자가 정한 발음 대응을 적용한다.
- 현재 위치 주변을 우선 탐색하며 반복 발화로 진행률을 중복 증가시키지 않는다.
- 건너뛴 구간은 검토 대상으로 남기고 추적 가능한 다음 구간을 찾는다.
- 침묵 중 자막을 자동 진행시키지 않는다.
- 임시 인식과 확정 인식 상태를 분리한다.
- 수동 원문 위치 이동은 정확한 발화로 채점하지 않는다.
- 인식 중단 시 실제 상태를 알리고 가능한 경우 녹화를 계속한다.

## 8. 시간 계산과 가로 막대

| 변수 | 정의 |
|---|---|
| T | 목표 발표 시간, 기본 600초 |
| M | 최대 녹화 시간, 900초 |
| E | 누적 활성 발표 시간, 침묵 포함·일시정지 제외 |
| N | 발화 대상 원문 전체 분량 |
| C | 추적 위치까지의 원문 분량 |
| p | 현재 진행률 C/N |
| R | 권장 도달 시간 T×p |
| F | 예상 총 시간 E/p |

- 분량은 공백·문장부호를 제외한 비교 문자열 기준으로 계산한다. 발음 대응이 있으면 해당 발음 분량을 사용한다.
- E−R이 양수면 권장 속도보다 늦고 음수면 빠르다.
- 30초 이상 진행하고 원고의 5% 이상에 도달한 뒤 예상 시간을 표시한다.
- 초기에는 '발표 속도 측정 중'을 표시한다.
- 예측은 평활화하여 급격한 변동을 줄이고 '현재 속도 기준'임을 표시한다.
- 추적 불확실 또는 수동 이동 직후에는 예측을 잠시 중단한다.
- 목표·예상 막대는 동일한 시간 축을 사용한다.
- 목표는 파란색, 예상은 청록색, 목표 초과 부분은 주황색으로 구분한다.
- 실제 경과 시간은 세로 커서, 권장 도달 시간은 점선 표식으로 표시한다.
- 시간 축은 최소 15분을 포함하고 녹화 한도를 표시한다. 더 긴 예측은 축을 확장하여 보여 준다.
- 예상 총 시간이 15분을 넘어도 예측값을 잘라 표시하지 않는다.
- 10분 목표를 넘으면 초과 시간을 알리면서 녹화를 계속한다.

예: 목표 600초, 경과 200초, 진행률 30%이면 권장 도달은 180초, 지연은 20초, 예상 총 시간은 약 667초다.

## 9. 녹화와 15분 한도

- 사용자의 시작 동작 이후에만 녹화한다. 미리보기와 녹화를 구분한다.
- 카운트다운 3초와 명시적 일시정지는 녹화 한도에서 제외한다.
- 일시정지 시 녹화·타이머·추적을 함께 멈추고 재개 시 같은 세션을 이어 간다.
- 14분과 14분 30초에 종료 예고를 표시한다. 알림음은 녹화 음성에 섞이지 않도록 사용하지 않는다.
- 활성 시간 900초에 종료를 요청하고 마지막 녹화 조각까지 저장한다.
- 원고를 끝내지 못했어도 한도를 적용한다. 추가 연습은 새 세션에서 한다.
- 결과 화면에 자동 종료 사유, 실제 시간, 일시정지 여부, 원문 진행 상태를 표시한다.

## 10. 저장·재생·내보내기

- 기본 저장 위치는 현재 기기의 브라우저 내부 저장소다.
- 영상 조각을 순차적으로 저장하여 중단 시 가능한 범위의 복구를 지원한다.
- 서버나 GitHub에 영상을 자동 업로드하지 않는다.
- 저장 완료 전에 탭을 닫으려 하면 경고한다.
- 녹화 기록을 선택하면 영상과 원문 대조를 재생한다.
- 검토 후보 선택 시 해당 발화 직전으로 이동한다.
- 실제 발화 오류와 인식 오류를 사용자가 확인하여 기록한다.
- 파일 내보내기는 지원되는 영상 형식을 사용하며 모든 기기에서 MP4를 보장하지 않는다.
- PC는 다운로드/선택 폴더, 모바일은 지원하는 파일 앱·다운로드·공유 경로를 제공한다.
- 사진 앱에 자동 저장하지 않는다. 지원되는 공유 경로에서 사용자가 선택한다.
- 브라우저 데이터 삭제·공간 회수로 내부 기록이 사라질 수 있음을 안내한다.
- 세션 삭제 시 해당 영상 조각과 대조 기록을 함께 삭제한다.

## 11. 구현 구조와 목표 기기

- 반응형 정적 웹 UI와 선택적 Node.js 음성 인식 서버.
- 카메라/녹화, 음성 인식, 원문 정렬, 시간 계산, 저장을 별도 계층으로 분리한다.
- 음성 인식은 브라우저 방식과 서버 방식을 교체할 수 있게 한다.
- 카메라·마이크는 보안 컨텍스트에서 사용한다. 모바일 배포는 HTTPS를 기준으로 한다.
- 목표 환경: iPhone Safari, iPad Safari, Android Chrome, PC Chrome/Edge.
- 목표 환경 목록은 실제 검증 완료 목록과 구분한다.

## 12. 개인정보와 보안

- 로그인 없이 기기 내 연습을 우선한다.
- 음성 인식 방식별 오디오 전송 사실을 시작 전에 안내한다.
- 서버 API 키는 서버 환경 변수에만 보관하고 브라우저 코드에 넣지 않는다.
- 서버 음성 요청은 이용 비밀번호와 출처 검사, 크기·빈도 제한을 적용한다.
- 원고·오디오·영상 본문을 일반 로그에 기록하지 않는다.
- 개인 영상, API 키, 실제 연습 기록은 GitHub 저장소에 포함하지 않는다.

## 13. 예외 상황

| 상황 | 기대 동작 |
|---|---|
| 권한 거부 | 허용 방법과 재시도 안내 |
| 음성 서비스 실패 | 인식 중단 표시, 가능한 경우 녹화 유지 |
| 저장 공간 부족 | 명확한 실패 안내, 보존된 영상 파일 내보내기 |
| 앱 전환·화면 잠금 | 감지 가능한 경우 일시정지, 복귀 후 상태 안내 |
| 카메라·마이크 연결 종료 | 보존된 데이터로 녹화 마무리 |
| 원고 추적 실패 | 위치 확인 중 표시, 직접 문장 선택 |
| 기기 회전 | 세션 유지, 레이아웃 재배치 |
| 강제 종료 | 마지막 저장 조각 범위에서 복구 시도, 완전 복구 보장 금지 |

## 14. 데이터 모델

- 원고 설정: 제목, 원문, 발음 대응, 목표 시간.
- 세션: ID, 해당 원문 스냅샷, 생성 시각, 목표, 실제 시간, 인식 방식, 녹화 형식, 일시정지 이력, 상태, 종료 사유.
- 영상 조각: 세션 ID, 순번, Blob.
- 대조 이벤트: 발화 텍스트, 시작·종료 시각, 원문 위치, 문자 상태, 불확실 여부, 사용자 검토 결과.

새 원고 수정은 이전 세션의 원문 스냅샷에 영향을 주지 않는다.

## 15. 수용 기준

1. 휴대폰·태블릿에서 카메라·하단 자막·시간 비교를 사용할 수 있다.
2. 원문을 자동으로 한 글자도 변경하지 않는다.
3. 발화에 따라 자막 상태가 변하고 불확실한 인식을 확정 오류로 단정하지 않는다.
4. 조사·어미 변경을 검토 후보로 검출한다.
5. 침묵은 시간에 포함하고 일시정지는 제외한다.
6. 600초 목표, 200초 경과, 30% 진행에서 R=180초, F≈667초를 계산한다.
7. 목표·예상 막대가 동일 축을 쓰고 목표 초과 영역을 구분한다.
8. 10분에는 계속 녹화하며 15분에는 자동 종료·저장한다.
9. 목표 기기별 실제 15분 영상 재생·파일 저장을 검증한다.
10. 회전·권한 거부·서비스 실패·저장 실패 시 상태와 다음 행동이 명확하다.
11. 색을 구별하지 못해도 상태를 알 수 있다.
12. 초기 성능 목표는 자막 반영 95백분위 2초, 재생 동기 오차 500ms 이내다. 구현 방식별 미달 여부는 구현 현황에 명시한다.

## 16. 개발·검증 순서

1. 카메라와 음성 인식의 동시 동작을 목표 실제 기기에서 확인한다.
2. 원고·반응형 화면·녹화·타이머를 구현한다.
3. 원문 대조와 수동 복구를 연결한다.
4. 예측 시간과 가로 막대를 연결한다.
5. 저장·재생·파일 내보내기·검토 흐름을 확인한다.
6. 실제 10분 발표와 15분 녹화로 지연·발열·저장 안정성을 검증한다.

## 17. 변경 이력

- 1.0: 휴대폰·태블릿·PC용 초기 요구사항.
- 1.1: 최대 녹화 15분, 자동 종료·저장 추가.
- 1.2: 브라우저 저장과 파일 내보내기 위치 명확화.
- 1.3: 앱 소스와 같은 저장소에 통합하고 구현 현황 문서와 연결.
