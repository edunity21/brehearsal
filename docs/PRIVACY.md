# 데이터 저장·전송 안내

## 기기에 저장되는 항목

- 원고와 발음 대응, 제목, 목표 시간: 브라우저 localStorage.
- 녹화 영상 조각, 전사 결과, 원문 대조, 일시정지 이력, 검토 결과: 브라우저 IndexedDB.
- 저장소 실패 시 종료 직후 영상: 현재 탭의 메모리. 탭을 닫으면 사라질 수 있음.
- 서버 이용 비밀번호: 현재 페이지 메모리에만 보관. 저장소에 기록하지 않음.

영상은 자동으로 외부 서버 또는 GitHub에 업로드하지 않습니다. 사용자가 파일 저장·공유를 선택하면 선택한 기기 경로/앱으로 전달됩니다.

## 외부로 전달될 수 있는 항목

- 브라우저 기본 음성 인식: 브라우저 제공자의 처리 방식에 따라 오디오가 해당 서비스로 전송될 수 있습니다.
- 서버 음성 인식: 약 5초의 WAV 오디오가 구성된 앱 서버를 통해 OpenAI 음성 전사 API로 전송됩니다. 서버 코드에는 오디오의 디스크 저장이나 본문 로그 기능이 없습니다.
- 서버는 원고 전체를 음성 인식 프롬프트로 보내지 않습니다.
- 서버 연결 시 이용 비밀번호가 HTTPS 요청 헤더로 앱 서버에 전송됩니다. API 키는 서버에서 OpenAI 요청에만 사용합니다.

외부 서비스의 실제 보관·처리 정책은 사용하는 계정과 서비스 계약에 따릅니다. 서버 운영자는 서비스를 공개하기 전에 자신의 처리 정책과 호스팅 로그 설정을 확인해야 합니다.

## 삭제와 내보내기

연습 기록에서 삭제하면 해당 세션의 브라우저 영상 조각과 메타데이터를 삭제합니다. 이미 다운로드하거나 다른 앱으로 공유한 파일은 별도로 삭제해야 합니다. 입력 원고 설정을 포함한 모든 내부 데이터를 제거하려면 브라우저의 해당 사이트 데이터 삭제 기능을 사용합니다.

브라우저 데이터 삭제, 비공개 모드 종료, 기기 저장 공간 회수로 기록이 사라질 수 있습니다. 보존할 영상은 파일로 내보내세요.
