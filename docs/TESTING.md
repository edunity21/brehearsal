# 테스트 안내

## 자동 검사

Node.js 22 이상에서 저장소 루트에서 실행합니다.

```sh
node --test tests/core.test.mjs tests/server.test.mjs tests/app.test.mjs
```

현재 자동 검사 항목:

1. 띄어쓰기와 문장부호 제외, 조사·어미 보존.
2. 약어 발음 대응과 원문 위치 매핑.
3. 연속 구간 일치와 진행 위치.
4. 조사 변경과 문장 내 누락 검토 표시.
5. 무관한 발화에 대해 진행하지 않음.
6. 반복 발화에서 진행률 중복 방지.
7. 권장·예상 시간 계산과 초기 예측 대기.
8. 10분에 계속 측정, 15분 한도, 일시정지 제외.
9. WAV 파일 헤더와 샘플 직렬화.
10. 정적 앱 제공, 비밀 파일 접근 차단, API 미설정 처리.
11. 서버 비밀번호·출처 검사, WAV 검증, 모의 전사 응답.
12. 합성 장치와 가상 시계로 앱 시작, 10분 계속 녹화, 일시정지·재개, 종료 예고, 15분 자동 종료, 저장소 실패 시 영상 내보내기 화면까지의 흐름.

서버 검사에는 모의 응답을 사용합니다. 실제 OpenAI API를 호출하거나 비용을 발생시키지 않습니다.

## 실제 기기 점검

다음 표는 수행해야 할 체크리스트이며 완료 기록이 아닙니다. 기기 모델, OS, 브라우저 버전, 시험 날짜를 함께 기록하세요.

| 점검 | 기대 결과 |
|---|---|
| HTTPS 주소로 접속 | 카메라·마이크 권한 요청 가능 |
| 30초 녹화 → 종료 → 재생 | 영상·음성이 함께 저장되고 재생됨 |
| 파일 내보내기 | 다운로드 또는 기기 공유 경로에서 파일 확인 |
| 정확한 원고 읽기 | 발화 후 자막 색 변경, 원문 자체는 유지 |
| 조사 하나 바꾸기 | 검토 후보 또는 불확실로 표시, 확정 채점하지 않음 |
| 한 문장 반복·건너뛰기 | 추적 유지 또는 수동 복구 가능 |
| 긴 문장 읽기 | 여러 줄에 걸쳐 현재 위치까지 자막 스크롤 |
| 10분 목표 초과 | 녹화 유지, 초과 페이스 표시 |
| 14분 및 14분 30초 | 무음 종료 예고 표시 |
| 15분 도달 | 자동 종료 후 마지막 영상 구간까지 저장 |
| 5분 녹화 + 1분 정지 + 10분 녹화 | 정지 제외 15분에 종료 |
| 세로·가로 전환 | 녹화와 타이머가 초기화되지 않음 |
| 다른 앱으로 이동 후 복귀 | 가능하면 일시정지, 명확한 상태 안내 |
| 네트워크 단절 | 음성 분석 실패 안내, 녹화는 가능한 경우 유지 |
| 저장소 부족 | 저장 실패 안내와 현재 메모리에서 내보내기 |
| 브라우저 재시작 | 동일 기기·브라우저에 저장된 기록 확인 |
| 원고에 HTML 문자열 입력 | HTML 실행 없이 일반 텍스트로 표시 |

목표 기기: iPhone Safari, iPad Safari, Android Chrome, PC Chrome/Edge. 실제 기기별 통과 여부를 확인한 뒤 지원 범위를 확정하세요.
